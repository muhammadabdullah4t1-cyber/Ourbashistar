# Muhammad Abdullah Portfolio

A responsive, black-and-crimson personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `abdullah_portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Files
- `index.html` — website content and page structure
- `style.css` — styling, responsive breakpoints, and animations
- `script.js` — mobile menu, reveal animations, and current footer year
- `images/abdullah-portrait.png` — portrait cutout with the original background removed

## Before publishing
- Confirm the portrait is the correct photo for Muhammad Abdullah.
- Confirm the TikTok and YouTube links are correct.
- Add any missing school/college details only if the client wants them displayed.
- The Font Awesome icons use a CDN; an internet connection is needed for those icons.
